# Ghidra Mobile AI

Projeto para desenvolver uma experiência mobile inspirada no Ghidra, com recursos de inteligência artificial para auxiliar na análise e adaptação de jogos.

## Objetivos

- Criar uma interface nativa para Android.
- Permitir importar arquivos de jogos.
- Exibir informações e metadados dos arquivos.
- Investigar a integração com componentes do Ghidra.
- Criar assistência por IA para analisar possíveis problemas em ports de jogos.
- Apresentar sugestões que possam ser revisadas pelo usuário.

## Arquitetura planejada

- Android: interface mobile.
- Ghidra Engine: camada de integração com ferramentas de análise.
- AI Assistant: assistência na análise e correção de ports.

## Status

Protótipo em planejamento. A compatibilidade do mecanismo do Ghidra com Android ainda precisa ser investigada.
